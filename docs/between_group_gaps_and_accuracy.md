# 组间差异（gap）与阈值上的逐组 accuracy

> 零重训，在既有 CV-OOF 预测上按 **averaging 口径**（逐折算 → 折间平均 → 再跨组取 min/max）重算。数字源 `outputs/conditioning_ablation/group_levels_averaging.json`，由 `scripts/build_group_levels_averaging.py` 产出并对既有 `oof_results_averaging.json` 做过逐位回归自检。

> **主阈值规则 = Youden J（val）**：每折在该折**验证集**上选一个**组无关**的全局阈值，施加到该折全部子群，指标折间平均。阈值从不接触评估数据。

> **显著性未做多重校正**：gap 与 accuracy 都是次要终点，按第 4 章 §4.3.3 不并入主终点的 Holm family，读时按 exploratory 对待。加粗 = 95% CI 不含 0。

## 结论（人工分析节）

> 以下为人工分析，`build_group_tables.py` 重跑不会覆盖。显著性口径：在每个终点内，
> 五个臂对 ERM 的比较做 **Holm 校正**（下称「Holm 后」）；主报告里 gap 与 accuracy 都是
> **次要终点**，按第 4 章 §4.3.3 不并入主终点的 family，这里的校正只是为了不让多重性
> 制造假象，不改变它们的次要地位。

### 1. 组间 gap：与 worst-group AUC 同调，全是 null

marginal gap 与 canonical gap 在四个 ID 数据集上**Holm 后无一显著**（未校正也只有 MIMIC 与
CheXpert 各 1 项）。两个 OOD regime 里只有 C2M 的 marginal gap 有 2 项越线
（SWAD +0.0039 变宽、HyperAdapt −0.0043 变窄），量级在千分位，且方向相反。

**gap 因此是对主结论的独立支持**：worst-group AUC 说「没抬起最差子群」，gap 说「也没把组间
差距压窄」，两条互不蕴含的读数指向同一判决。

⚠️ **但主表那句「gap follows the same pattern」仍须改写**。两者一致的是**判决**，不是**逐臂的
方向**：HAM 上 HyperAdapt 的 worst-group AUC 比 ERM 高 0.028，marginal gap 却几乎不动
（−0.029）而 canonical gap 反而**变宽** +0.004；Fitzpatrick 上 HyperFusion 的 worst-group
只高 0.0007，gap 却变宽 0.013。「同一个 pattern」这个说法在逐臂层面不成立。

**另有一处口径不一致要修**：既有 JSON 里的 `gap` 是 **canonical 分区**（含 joint 交叉格）的极差，
而主终点 worst-group 用的是 **marginal 分区**。两者数值差得不小（CheXpert ERM：marginal 0.0389
vs canonical 0.0516），报 gap 时必须说清用的是哪一套。本次已把 `marginal_gap` 补齐。

### 2. 逐组 accuracy：显著项很多，但没有一项支持 HN

两个小数据集（HAM、Fitzpatrick）上 worst-group accuracy 各有 2 项未校正显著
（HAM：HyperFusion +0.058 p=0.011、SWAD +0.042 p=0.020；Fitzpatrick：SWAD +0.026 p=0.017、
HyperHead +0.025 p=0.044），**Holm 后全部消失**。

两个大数据集与两个 OOD regime 上显著项则很多，但读不出对 HN 有利的结论，理由有三条：

**(a) 方向在数据集之间翻转。** MIMIC 上四个臂的 worst-group accuracy 显著**升高**
（+0.007~+0.010），CheXpert 上五个臂全部显著**降低**（−0.006~−0.040）；两个 OOD 方向同样相反
（M2C 升、C2M 降）。同一批方法在同模态、同任务的两个库上给出相反的符号。

**(b) accuracy 与 balanced accuracy 系统性打架。** MIMIC 上 worst-group accuracy 变好，
balanced accuracy 的 gap 却五个臂全部显著**变宽**；CheXpert 上 worst-group accuracy 变差，
balanced accuracy 的 gap 却五个臂全部显著**变窄**。两个指标只差一个患病率加权，却每次都给出
相反的公平判决——说明动的是阈值处的类别构成，不是子群内部的判别力。

**(c) 变动几乎完全由整模型的操作点平移解释。** Δ(worst-group accuracy) 与 Δ(overall accuracy)
在六个 regime 上的相关是 **+0.68 / +0.97 / +0.999 / +0.99 / +0.81 / +0.97**。也就是说
最差子群的 accuracy 只是跟着整体一起动，没有组间再分配。而且 **SWAD 这个属性盲的臂
每次都和 HN 一起同向移动**（如 CheXpert：SWAD −0.006、三个 HN −0.017/−0.026/−0.040），
所以这根本不是「条件化」带来的效应，是任何偏离 ERM 的权重都会带来的校准差异。

**结论：阈值口径没有翻盘。** 它既没给 HN 找到 AUC 口径漏掉的公平收益，也没有推翻既有结论；
它显著的地方全部落在「整模型操作点漂移」这一层，与属性条件化无关。

### 3. 三条工程结论（口径设计的实测依据）

**τ=0.5 不能当主口径。** CheXpert 患病率 8.2%，`half` 规则下 ERM 的 overall accuracy 是
**0.9207**，而 balanced accuracy 只有 **0.6014**——平凡的全判负分类器就有 0.918。用它逐组
报 accuracy，报的基本是各组的负样本占比。Youden 口径下则是 0.8166 / 有意义的判别。

**阈值必须逐折选、逐折施加。** HAM 的 ERM 五折 Youden 阈值是
0.060 / 0.002 / 0.069 / 0.026 / 0.239，跨两个数量级；HyperAdapt 是
0.043 / 0.027 / 0.030 / 0.012 / 0.174。把五折拼起来定一个阈值，等于把这些逐折校准漂移
整个吃进读数——这正是 pooled AUC 负偏的同一个病灶，而阈值类指标对它比 AUC 敏感得多。

**accuracy 必须与 balanced accuracy 成对报。** 见上面 (b)：单报任何一个都会得到一个
在另一库、另一指标上立刻反号的「结论」。
