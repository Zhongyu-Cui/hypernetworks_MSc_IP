## 0. 口径：为什么从 pooled-OOF 改为 averaging

### 0.1 旧口径的缺陷（学界已知，非本项目特有）

旧版把 5 折的预测**拼成一个向量再算一个 AUC**（pooling）。5 折是**5 个不同模型**，池化会构造出
**跨折正负对**（折 i 的阳性 vs 折 j 的阴性），这要求两个模型的分数**在同一把尺子上**——而这一假设不成立：

- **Parker, Günter & Bedo (2007)**, *BMC Bioinformatics* 8:326「Stratification bias in low signal
  microarray studies」——低信号数据上 pooled AUC 有严重**负偏**；**无信号数据 AUC 掉到 <0.3 而非 0.5**；
  **排序类指标（ROC/AUC）受害远重于 error rate**。
- **Airola, Pahikkala, Waegeman, De Baets, Salakoski (2010)**, *JMLR W&CP* 8:3–13（2011 *CSDA* 扩展版）
  ——原文：「pooling 假设各折分类器来自**同一总体**……计算 AUC 时该假设**更可疑，因为部分正负对由
  不同折的样本构成**」；推荐 **averaging** 或 **LPOCV**。
- **Forman & Scholz (2010)**, *SIGKDD Explorations* 12(1):49–57 ——各家聚合口径互不兼容，致文献不可比。

**本项目实测的近因 = 早停轮数异质**（Parker 的近因是 stratification，机制同源）：各折早停轮数不同 ⇒
训得久的折 logit 幅度大得多。实测 HAM 某 run 逐折 logit 中位数 `[-7.6, -4.0, -23.0, -6.0, -11.2]`
（**跨折差 19 个单位**），其**逐折 test AUC 均值 0.831（健康）却池化成 0.639（−0.192）**。

**致命之处：污染程度因方法系统性不同** ⇒ 组间比较测的是**校准漂移**而非真效应。
实测 `corr(跨折 logit 中位数 SD, 池化惩罚) = −0.607`。

| 数据集 | n | 跨折 logit SD | worst 池化惩罚 |
|---|---|---|---|
| **HAM10000** | 9.7k | 0.78–**2.59** | **−0.023 ~ −0.096** |
| **Fitzpatrick** | 16k | 0.83–**5.18** | −0.004 ~ −0.030 |
| MIMIC | 199k | 0.09–0.18 | −0.0005 ~ −0.003 |
| CheXpert | 138k | 0.12–0.39 | −0.001 ~ −0.009 |

**小数据集受害重、大数据集近乎免疫**（折内样本少 ⇒ 早停更飘 ⇒ 尺度更散）。

### 0.2 换 averaging **不损失评估 n**（对「池化抬 n」初衷的正面回应）

抬 n 的功劳来自 **CV 本身**（每个样本轮到一次 test ⇒ 全部样本都有干净的折外预测），**不是 pooling**；
两种聚合**都用满全部样本**。AUC 方差由**类别样本数**支配（`Var ≈ c/n_pos + c'/n_neg`）而非「正负对数」，
故「5 折各自估计再平均（÷5）」与「池化」精度相当。**实测反而更紧**：worst-group 的 bootstrap SE 之比
averaging/池化 = **0.72~0.92×**（C-Deep 收益最大——正是漂移最重的 cell）⇒ **pooling 独有的跨折对
只注入噪声、不带信息**。LPOCV 需按对重训、算力不可行，故取 averaging。

### 0.3 本版口径细则

| 项 | 口径 |
|---|---|
| **估计量** | **averaging**：逐折算指标 → 折间平均（**永不跨折池化分数**，无跨折正负对） |
| **worst / best** | **先平均后 min/max**：`min_g[mean_f AUC(g,f)]`。Jensen 恒有 `mean_f[min_g …] ≤ min_g[mean_f …]`；选后者因①「先 min」让每折在最噪处取极值、放大 min 的向下偏，②「模型在哪组最弱」应是模型属性、不该每折换答案 |
| **子群 schema** | 取自 `harness.subgroup_auc.subgroup_masks`（**单一事实来源**）。**canonical** = 全部子群（含 joint 交叉）；**marginal** = 仅单属性边缘组（排含 `|` 者） |
| **推断** | **患者/病灶级配对 cluster bootstrap**（B=1000；全方法共用同一批重采样索引；只重采样 cluster）。聚类键：HAM=`lesion_id`、PAPILA=`pid`（双眼相关）、MIMIC/CheXpert=`patient_id`；**Fitzpatrick 每 md5hash 唯一、无聚类结构 ⇒ 样本级（正确）** |
| **选择** | 沿用旧版：早停=val Overall AUC；config=折均 marginal-worst。**选择只用 val、评估只用 test**，两者永不交叉 |

### 0.4 ⚠️ averaging 的已知代价（Airola 明示，本版如实报告）

小 joint 格可能**某折只剩一类 ⇒ 该折 AUC 无定义**。处理 = **跳过该折、用其余折平均**，并报计数：

| 数据集 | 无定义折-格 | 说明 |
|---|---|---|
| HAM10000 | **1** / 40 | fold4 的 `sex:Male|age:20-40`：n=127 但 n_pos=0 |
| **PAPILA** | **5** / 40 | 每折仅 84 例 ⇒ joint 格约 10 例 |
| 其余 | 0 | — |

⇒ **PAPILA 的 canonical worst 不可解读**（见 §2）。

### 0.5 ⚠️ ROC 不能用 AUC 评（旧版即有的问题，非本版引入）

ROC 是**操作点（阈值）方法**：按组给分数加**常数偏移** ⇒ **组内排序不变 ⇒ 组内 AUC 不变**。
AUC 是**阈值无关**的排序指标，**捕捉不到 ROC 的机制**。故下表中 ROC 的 worst-group 近乎恒等于 ERM
（PAPILA 处因 θ≈0 而**逐位相同**）。**ROC 的真实评估须看操作点指标（TPR/FPR/EqOdds）**，不在本文件。

| **C→M** | **HyperAdapt** | **−0.0051 显著劣** | **+0.0017 显著优** | 🛑 **变号，且两侧都显著** |
| **C→M** | HyperHead / HyperFusion | −0.0051 / −0.0045 **显著劣** | −0.0001 / −0.0002 **n.s.** | 🛑 **「全 HN 显著更差」被推翻** |

### 被推翻的三条旧版核心结论

1. **~~「深层 HN（HyperFusion/HyperAdapt）在 M→C 稳健胜」~~** → **只有 HyperAdapt 胜**；
   HyperFusion 的 +0.0058 里约 **3/4 是漂移**（→+0.0015 n.s.）。
2. **~~「C→M 全 HN 显著更差」~~** → **HyperHead/HyperFusion 打平，HyperAdapt 反而显著微优**。
3. **~~「强烈方向不对称（M→C 胜 / C→M 全输）」~~** → **不成立**：HyperAdapt 在**两个方向都显著为正**
   （M→C +0.0045、C→M +0.0017）。旧版据此推出的「**反向无信号可迁移**」解释**失去经验基础**。

### 附带澄清（修正一次错误归因）

`conditioning_ablation_plan.md` §0.2 曾把「M→C legacy k→k 与 full-target 三处变号」归因于**估计量选择**
（k→k vs full-target）。**实为聚合方式**（pooling vs averaging）：k→k 预测改用 averaging 后即与
full-target 吻合（见 §1.6 的交叉验证）。full-target 因**逐 (f,s) 算指标再平均、从不跨折池化**而天然免疫。

## 3. 修订后的跨数据集结论

### 3.1 SWAD 仍是 ID 最强，但 OOD 会翻车

| regime | SWAD vs ERM（marginal worst） |
|---|---|
| HAM | **+0.0457 显著** |
| Fitzpatrick | **+0.0578 显著** |
| MIMIC | **+0.0016 显著** |
| CheXpert | −0.0023 n.s. |
| **M→C OOD** | **−0.0044 显著劣** |
| C→M OOD | −0.0012 n.s. |

→ **SWAD 在 3/5 ID regime 显著胜 ERM（小数据集上幅度可观 +0.046~+0.058），但在 M→C OOD 上显著劣于 ERM。**

### 3.2 HN：只有 HyperAdapt 一致微弱为正，且幅度全在「微弱档」

| regime | HyperHead | HyperFusion | **HyperAdapt** |
|---|---|---|---|
| HAM (≈0) | +0.0182 n.s. | +0.0334 n.s. | +0.0212 n.s. |
| Fitzpatrick (I≈0) | +0.0266 n.s. | +0.0007 n.s. | +0.0170 n.s. |
| PAPILA (I≈0) | −0.0375 n.s. | −0.0323 n.s. | −0.0123 n.s. |
| MIMIC (决定性 0) | +0.0004 n.s. | +0.0001 n.s. | **+0.0022 显著** |
| CheXpert (I≈0) | **−0.0040 显著劣** | **+0.0029 显著优** | −0.0023 n.s. |
| **M→C OOD** | +0.0020 n.s. | +0.0015 n.s. | **+0.0045 显著** |
| **C→M OOD** | −0.0001 n.s. | −0.0002 n.s. | **+0.0017 显著** |

- **HyperAdapt（条件化最遍布）是唯一在多个 regime 一致显著为正的 HN**（MIMIC +0.0022、M→C +0.0045、
  C→M +0.0017），且**从未显著劣**。但**幅度全部 <0.005（微弱档）**，且三处显著都出现在 **n≥138k** 的
  大数据集——**统计显著 ≠ 实际重要**。
- **小数据集（HAM/Fitz/PAPILA）三个 HN 全 n.s.**（CI 宽 ±0.05~0.10）⇒ 功效不足，无法判别。
- 命名模型排序 **HyperAdapt > HyperFusion ≈ HyperHead** **与「范围越深越好」方向一致**——但三者在
  **范围/参数化/调制/容量/初始化上同时不同（混杂）**，**不能归因给范围**。

### 3.3 与受控范围消融的交叉印证（关键）

`docs/conditioning_ablation_plan.md` 的 **E1**（`ResNet18CondNet`，**锁死其余全部轴、只改条件化范围**）
在 HAM 上给出 **H1/H2 均 n.s.、最小观测有效配置 = 无**；其 **ρ_l 诊断**进一步显示：
**conv 的条件化偏移仅 1.3~2%，而 fc 高达 ~100%** ⇒ **条件化几乎全由 fc 承担、backbone conv 的
adapter 优化根本没用起来**（「挂了 adapter」≠「用了 adapter」）。

⇒ **合起来的推论**：HyperAdapt 的微弱一致优势**可能来自范围以外的轴**（容量/参数化/初始化），
而非「条件化更深」本身。这是本项目目前对「为何 HyperAdapt 略优」最站得住的表述。

### 3.4 全研究一句话（修订版）

> **属性条件化超网络（HN）在 worst-group 公平上没有实际重要的收益。** 小数据集（HAM/Fitz/PAPILA）
> 上三个 HN 全部不显著；大数据集上只有 **HyperAdapt** 一致显著微优（+0.002~+0.005，**微弱档**，
> 且显著性主要由 n≥138k 撑起）。**SWAD 在 3/5 ID regime 显著胜 ERM 且幅度大得多**（+0.046~+0.058），
> 是更划算的公平基线——但它在 M→C OOD 上显著劣于 ERM。旧版的「深层 HN 稳健胜」「C→M 全 HN 显著更差」
> 「强烈方向不对称」**均为 pooled-OOF 的校准漂移伪影，已推翻**。

## 4. 边界与限制（必读）

1. **§0.4 averaging 的代价**：PAPILA 5/40、HAM 1/40 折-格 AUC 无定义（跳过该折平均）
   ⇒ **PAPILA 的 canonical worst 与 gap 不可解读**。
2. **§0.5 ROC 不能用 AUC 评**（操作点方法，组内 AUC 不变）⇒ 本文件中 ROC 的数字**无方法学意义**，
   仅为完整性列出；其真实评估须看操作点指标。
3. **大 n 下显著 ≠ 重要**：MIMIC/CheXpert/OOD 的多数 Δ<0.005，属「微弱」档。
4. **未做多重比较校正**：本文件是**描述性结果表**（每 regime 5 个方法 × 2 个参照）。确认性判决
   （Holm family）见 `conditioning_ablation_plan.md`。
5. **worst-group 的动态 argmin 有向下偏**：小数据集上 argmin 在候选组间频繁翻转
   （HAM 实测主导组仅 53~67%）⇒ Δ 估计**偏保守**（校准实测偏差 −0.006、覆盖率 80%）
   ⇒ 小数据集的 n.s. **不可**解读为「确无效应」，只能说「**未观测到可检出的增量**」。
6. **本版零重训**：与旧版消费同一批逐折预测。若日后重训（如改早停准则以减小跨折尺度漂移），
   数字会再变。**根治之道是让各折训练长度可比，而非仅在评估端补救。**
